NBA Live · 三套 UI 方案对比

同一份需求基线（暗色默认 / 播放红 CTA / 三核心屏 / 多线路切换 / 故障自动切换 / 空载错三态），三种设计取向。
截图均为 390×844 真实视口渲染，使用真实赛事与队徽数据。

方案 A · 影院沉浸 推荐

深黑 OLED 打底，把比赛当作"正在放映的片子"。直播中的赛事用红色光晕呼吸突出， 播放器做成沉浸式暗场，信号切换以半透明胶囊条贴在视频下方。观赛氛围最强。

方案 B · 运动卡片 SPORT CARD

明快、有活力的运动视觉。大圆角卡片 + 联赛色条 + 大字号开赛时间， 双列网格让一屏看到更多场次。播放器带"其他直播"推荐区，方便连着看。

方案 C · 极简赛程表 MINIMAL

完全反卡片化。把应用做成一份优雅的赛程表：一行一场，时间 / 联赛 / 对阵 / 线路数横向排布， 靠排版与留白建立秩序。信息密度最高，操作路径最短。
